# QR Binary Android

Android-приложение для QR-кодов, содержащих сырые байты изображений (GIF/PNG/JPEG).

## Возможности

- CameraX + ML Kit для сканирования QR в реальном времени.
- Используется `Barcode.rawBytes`, а не `rawValue`.
- Распознавание GIF/PNG/JPEG по сигнатуре.
- Сохранение изображения в `Загрузки`.
- Предпросмотр GIF через Glide.
- Импорт QR-кода как изображения из галереи.
- Генерация QR Version 40, Error Correction L.
- Ограничение одного QR: 2953 байта.
- Автосжатие JPEG/PNG в JPEG; GIF не ломается и поэтому не сжимается автоматически.
- SHA-256 проверка созданного QR.
- История последних сканирований.
- Фонарик и tap-to-focus.
- Тёмная тема Material 3.

## Важное замечание про QR byte mode

Приложение сохраняет бинарные значения 0..255 через однозначное отображение ISO-8859-1. Это позволяет ZXing записывать содержимое как QR byte mode без UTF-8-порчи исходных байтов.

Для декодирования сканер читает `Barcode.rawBytes`.

## Ограничение 2953 байта

2953 байта — максимальная полезная нагрузка для Version 40 / Error Correction L в byte mode. Реальный код дополнительно задаёт Version 40 и проверяет размер до генерации.

## Сборка без Android Studio

Gradle Wrapper (`gradle-wrapper.jar`) в репозитории не нужен: GitHub Actions устанавливает Gradle 8.7 через `gradle/actions/setup-gradle@v3`.

### 1. Создать GitHub-репозиторий

На GitHub:

1. Нажмите `New repository`.
2. Назовите его, например, `QRBinary`.
3. Можно оставить Public или выбрать Private.
4. Создайте пустой репозиторий.

### 2. Загрузить файлы с телефона

Через сайт GitHub:

1. Откройте репозиторий.
2. `Add file` → `Upload files`.
3. Перенесите все файлы и папки проекта.
4. Убедитесь, что файл workflow находится именно здесь:
   `.github/workflows/build.yml`
5. Нажмите `Commit changes`.

GitHub создаст коммит в `main`, и сборка запустится автоматически.

### 3. Запустить вручную

Откройте:

`Actions` → `Build Android APK` → `Run workflow`.

Выберите `main` и запустите workflow.

### 4. Скачать APK

После успешной сборки:

`Actions` → нужный запуск → внизу `Artifacts` → `QRBinary-debug`.

Скачайте ZIP артефакта и достаньте из него `app-debug.apk`.

### 5. Установить APK

Перенесите APK на телефон и откройте его.

Android может попросить разрешить установку приложений из неизвестного источника для браузера/файлового менеджера. Разрешите её только для приложения, через которое вы устанавливаете собственный APK.

## Первый запуск

ML Kit может скачать модель сканирования при первом использовании. Поэтому первый запуск сканера может потребовать интернет.

Для сканирования разрешите доступ к камере.

На Android 13+ приложение запрашивает доступ к изображениям для работы с галереей. На Android 12 и ниже используется `READ_EXTERNAL_STORAGE`; на Android 9 также нужен `WRITE_EXTERNAL_STORAGE` для сохранения в Downloads.

## Структура

- `MainActivity.kt` — нижняя навигация.
- `ScannerFragment.kt` — CameraX/ML Kit.
- `GeneratorFragment.kt` — выбор изображения, сжатие и генерация QR.
- `QrDecoder.kt` — ML Kit.
- `QrEncoder.kt` — ZXing.
- `ImageFormatDetector.kt` — magic bytes.
- `FileSaver.kt` — MediaStore/legacy Downloads.
- `HistoryStore.kt` — локальная история.
- `Hashing.kt` — SHA-256.

## Важное замечание о проверке QR

Кнопка «Проверить» передаёт сгенерированное изображение QR обратно в ML Kit и сравнивает SHA-256 полученных байтов с байтами, которые приложение собиралось закодировать.

Это проверяет полный цикл `байты → QR → ML Kit rawBytes`.

## Примечание про QR размер

`scale = 20` используется как размер одного модуля при создании bitmap. Поле QR Version 40 содержит 177×177 модулей; вокруг него добавляется quiet zone согласно `MARGIN = 4`.
